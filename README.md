# Áquila Barbosa • Assessoria Imobiliária & Crédito Habitacional

Landing page institucional para a corretora **Áquila Barbosa** (CRECI SP 299970), especialista em crédito imobiliário, Minha Casa Minha Vida e imóveis na Zona Sul de São Paulo.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** semântico
- **CSS3 Moderno** (Vanilla CSS com Design System executivo, variáveis CSS, glassmorphism e animações)
- **JavaScript (ES6+)** nativo (sem dependências pesadas)
- **Google Maps Embed** integrado para visualização das regiões atendidas

## 📂 Estrutura do Projeto

```text
├── assets/
│   ├── icons/          # Ícones e favicons
│   └── images/         # Imagens da corretora, hero banner e logo
├── css/
│   ├── animations.css  # Efeitos de scroll, flutuação e transições
│   └── style.css       # Estilos globais e componentes da landing page
├── js/
│   ├── counter.js      # Contador numérico de métricas
│   ├── main.js         # Controle de menu, scroll e interações
│   ├── simulator.js    # Lógica de cálculo e simulação
│   └── slider.js       # Carrossel e slider de depoimentos/imóveis
├── index.html          # Página principal
└── README.md
```
